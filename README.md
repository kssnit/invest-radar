# 투자 레이더 · 갤럭시 S20 버전

안 쓰는 갤럭시 S20을 **24시간 알림 봇**으로 만들어요.
DART 공시, 나라장터 개찰결과, 방산 전시회 같은 일정을 확인해서 **디스코드로 알림**을 보내고, **대시보드 웹페이지**도 갱신해요.

| 확인 대상 | 평일 07~22시 | 밤·주말 |
|---|---|---|
| DART 공시 | **1분마다** | 10분마다 |
| 나라장터 개찰결과 | 10분마다 | 30분마다 |
| 일정 (D-7, D-1, 당일) | 아침 8시 이후 1번 | |

| 알림 | 뜻 |
|---|---|
| 🚨 주의 | 유상증자, 전환사채, 거래정지, 입찰참가자격 제한 같은 악재성 공시 |
| 📈 호재 | 공급계약, 수주, 자사주 취득·소각, 우선협상 같은 호재성 공시 |
| 📄 공시 | 그 밖의 공시 |
| 🏛️ 개찰 | 관심 회사나 키워드(위성, 천궁 등)가 들어간 나라장터 개찰결과 |
| 📅 일정 | 전시회·결정 시한 알림 |
| ▶️ ⏹️ | 봇 시작·종료 |
| ⚠️ ✅ | 확인이 30분 넘게 실패하면 경고, 다시 되면 복구 |
| 📵 | S20 봇이 1시간 넘게 응답이 없을 때 (GitHub가 감시해요) |

알림은 **평소 쓰는 휴대폰의 디스코드 앱**으로 받아요. S20은 봇만 돌려요.

## 전체 순서 (약 40분, 휴대폰만으로 할 수 있어요)

1. 키 3개 발급 (OpenDART, 공공데이터포털, 디스코드)

## 1. 키 발급

### ① OpenDART 인증키
https://opendart.fss.or.kr 가입 → **인증키 신청/관리 → 인증키 신청** → 40자리 키 복사

### ② 공공데이터포털 인증키 (나라장터용, 없어도 봇은 동작해요)
https://www.data.go.kr 로그인 → **조달청_나라장터 낙찰정보서비스** 검색 → **활용신청**
→ **마이페이지 → 데이터 활용 → Open API → 활용신청 현황**에서 **일반 인증키(Decoding)** 복사
(승인 직후 몇 시간은 키가 안 될 수 있어요)

### ③ 디스코드 웹후크 주소
1. 디스코드에서 내 서버를 만들어요 (왼쪽 **+ → 직접 만들기**).
2. 알림 받을 채널 → **채널 편집(톱니바퀴) → 연동 → 웹후크 → 새 웹후크 → 웹후크 URL 복사**
   (앱에서 메뉴가 안 보이면 휴대폰 브라우저로 discord.com 에 로그인해서 하세요)
3. 이 주소는 비밀번호처럼 다루세요.

## 2. GitHub 준비

### 저장소 만들기
1. https://github.com 가입 → 오른쪽 위 **+ → New repository**
2. 이름 `invest-radar`, **Public**, **Add a README file** 체크 → **Create repository**

### 토큰 만들기 (S20이 대시보드 파일을 올릴 때 써요)
1. 프로필 사진 → **Settings** → 맨 아래 **Developer settings** → **Personal access tokens → Fine-grained tokens → Generate new token**
2. 아래처럼 고르고 **Generate token**:
   - Token name: `invest-radar-phone`
   - Expiration: 원하는 기간 (최대 1년. 만료되면 디스코드로 ⚠️ 알림이 와요)
   - Repository access: **Only select repositories → invest-radar**
   - Repository permissions: **Contents → Read and write**, **Workflows → Read and write**
3. `github_pat_` 로 시작하는 토큰을 복사해 두세요. 다시 볼 수 없어요.

## 3. S20에 Termux 설치

1. S20 브라우저로 https://f-droid.org 에 들어가 **F-Droid** 앱을 내려받아 설치해요.
   ('출처를 알 수 없는 앱 설치' 허용 창이 나오면 허용)
2. F-Droid에서 **Termux**와 **Termux:Boot**를 설치해요.
   - 구글 플레이의 Termux는 쓰지 마세요. 섞어서 설치하면 오류가 나요.
3. **Termux:Boot** 앱을 **한 번 열었다 닫아요.** (휴대폰이 재부팅되면 봇을 자동으로 켜 주는 앱이에요)

## 4. 봇 설치 (명령 한 줄)

1. 이 zip 파일(`invest-radar.zip`)을 S20의 **다운로드** 폴더에 저장해요.
   이름이 `invest-radar (1).zip` 처럼 바뀌었으면 `invest-radar.zip` 으로 바꿔 주세요.
2. Termux를 열고 아래를 입력해요. 저장공간 허용 창이 나오면 **허용**을 눌러요.
   ```
   termux-setup-storage
   ```
3. 아래 한 줄을 **길게 눌러 붙여넣기** 하고 엔터를 눌러요. (중간에 질문이 나오면 그냥 엔터)
   ```
   pkg update -y && pkg install -y python unzip procps curl && unzip -o ~/storage/downloads/invest-radar.zip -d ~ && bash ~/invest-radar/termux/install.sh
   ```
4. 안내에 따라 키를 하나씩 붙여넣어요.
   - ① OpenDART 인증키 ② 공공데이터포털 인증키 ③ 디스코드 웹후크 ④ GitHub 저장소 (`내아이디/invest-radar`) ⑤ GitHub 토큰
5. 디스코드에 **🔔 테스트 알림**, **▶️ 투자 레이더 시작**, **✅ 연결 완료**가 오면 성공이에요.

키는 S20 안의 `.env` 파일에만 저장되고, GitHub에는 올라가지 않아요.

## 5. GitHub 마무리

1. **대시보드 켜기**: 저장소 **Settings → Pages** → Source **Deploy from a branch**, Branch **main**, 폴더 **/docs** → **Save**
   1~2분 뒤 `https://내아이디.github.io/invest-radar/` 에서 보여요. 평소 휴대폰에서 **홈 화면에 추가**하세요.
2. **멈춤 감시 켜기**: 저장소 **Settings → Secrets and variables → Actions → New repository secret**
   - Name: `DISCORD_WEBHOOK_URL`, Secret: 디스코드 웹후크 주소
3. **Actions** 탭 → (처음이면 enable 버튼) → **휴대폰 봇 감시 → Run workflow** 로 한 번 실행해 봐요.
   이후 30분마다 S20이 살아 있는지 확인하고, 1시간 넘게 소식이 없으면 📵 알림을 보내요.

## 6. 갤럭시 S20 설정 (봇이 꺼지지 않게)

안드로이드는 배터리를 아끼려고 백그라운드 앱을 끄기 때문에, 아래 설정이 꼭 필요해요.

1. **설정 → 애플리케이션 → Termux → 배터리 → 제한 없음**
   (Termux:Boot도 똑같이)
2. **설정 → 배터리 및 디바이스 케어 → 배터리 → 백그라운드 사용 제한**
   - **사용하지 않는 앱을 절전 상태로 전환** 끄기
   - **절전 예외 앱**에 Termux, Termux:Boot 추가
3. **배터리 보호 켜기**: 설정 검색창에 `배터리 보호` 입력 → 켜기
   (24시간 충전해도 85%까지만 충전해서 배터리가 부풀지 않게 해 줘요)
4. **자동 최적화의 '자동으로 다시 시작'** 은 꺼 두는 걸 권해요. 켜 둬도 Termux:Boot가 봇을 다시 켜 주지만, 꺼 두는 편이 더 안정적이에요.
   (메뉴 이름은 소프트웨어 버전에 따라 조금 다를 수 있어요)
5. S20은 **충전기와 와이파이에 연결**해 두세요. 화면은 꺼져도 돼요.
   알림창에 Termux 알림이 계속 떠 있으면 정상이에요.

## 종목·키워드·일정 바꾸기

**GitHub 저장소에서 `config.json` 을 고치면** 10분 안에 S20 봇이 알아서 가져가요. 반영되면 디스코드에 **⚙️ 설정 변경을 반영했어요**가 와요. (평소 휴대폰 브라우저에서 파일 열기 → 연필 아이콘 → 고치기 → Commit changes)

- **종목 추가**: `companies` 에 한 줄 추가 (종목코드 6자리, `held` = 보유 여부)
  ```json
  {"name": "한국항공우주", "stock_code": "047810", "held": false},
  ```
- **ETF·미국 주식 추가**: `"type"` 을 붙이면 공시 확인 없이 시세만 받아요 (카드·차트·지표는 똑같이 나와요).
  ```json
  {"name": "KODEX 미국S&P500(H)", "stock_code": "449180", "type": "etf", "held": true},
  {"name": "엔비디아", "stock_code": "NVDA.O", "type": "us", "held": true},
  {"name": "코카콜라", "stock_code": "KO", "type": "us", "held": true},
  ```
  미국 주식은 나스닥이면 `.O` 를 붙이고(NVDA.O), 뉴욕증권거래소는 티커만 적어도 봇이 알맞은 코드를 찾아요.
- **보유 / 미보유 바꾸기**: 그 종목의 `"held"` 만 `true`(보유) ↔ `false`(미보유)로 바꾸면 돼요.
  | | 디스코드 알림 | 대시보드 | 확인 간격 |
  |---|---|---|---|
  | 💼 보유 (`true`) | 모든 새 공시 | 전부 | 기본 (낮 1분) |
  | 👀 미보유 (`false`) | 🚨 주의 · 📈 호재 키워드 공시만 | 전부 | 3배 (낮 3분) |
  - 알림 제목에 `[한화시스템 · 보유]`, `[한국항공우주 · 미보유]` 처럼 붙어요. 대시보드에서는 💼 보유 / 👀 미보유 칩으로 걸러 볼 수 있어요.
  - 알림 범위 바꾸기: `dart` 의 `"alert_held"`, `"alert_unheld"` 에 `all`(모든 공시) / `keywords`(주의·호재만) / `none`(알림 없음, 대시보드만)
  - 미보유 확인 간격: `schedule` 의 `"dart_unheld_every"` (3 = 보유 종목 3번 확인할 때 1번)
  - 새로 추가한 종목의 지난 공시는 알림 없이 대시보드에만 담아요 (알림 폭탄 방지).
  - `🚨 멘션(mention_on_danger)`은 보유 종목에만 붙어요.
- **일정 추가**: `events` 에 추가 (날짜는 `YYYY-MM-DD`)
  ```json
  {"name": "한화시스템 실적발표", "start": "2027-02-05", "end": "2027-02-05", "place": "", "note": "자금 조달 언급 확인"},
  ```
  결과가 나온 일정은 `"status": "done"` 을 붙이면 대시보드에 '결과' 표시로 `end` 날짜까지 보여요. 일정이 4개보다 많으면 '더 보기'로 펼쳐져요.
- **공시 분류**: `danger_keywords`(🚨), `good_keywords`(📈)
- **나라장터**: `company_keywords`(개찰 결과에 이 회사가 나오면 알림), `title_keywords`(사업명에 이 단어가 있으면 알림)
- **확인 주기**: `schedule`
  - `fast_hours`: 빠르게 확인할 시간대 (기본 7시~22시)
  - `dart_fast_seconds`: 그 시간대의 공시 확인 간격 (기본 60초)
  - 그 외 항목: 밤·주말 간격, 나라장터 간격
- 고친 내용에 오류가 있으면 봇은 이전 설정을 계속 쓰고, 디스코드로 ⚠️ 알려줘요.
- 목록의 마지막 줄 뒤에는 쉼표를 붙이지 마세요.

## 휴대폰 홈 화면에 앱처럼 두기

대시보드는 홈 화면에 설치할 수 있는 웹앱이에요. 레이더 아이콘을 누르면 주소창 없이 전체 화면으로 열려요.
- **삼성 인터넷**: 대시보드 주소를 열고 주소창 옆 **설치(↓) 아이콘** → 설치. 아이콘이 없으면 아래 메뉴(≡) → **현재 페이지 추가** → **홈 화면**.
- **Chrome**: 오른쪽 위 ⋮ → **홈 화면에 추가** → **설치**.

## 시세·주식 대시보드

대시보드 맨 위에 코스피·코스닥·미국 지수·환율·유가·금·국채 시세가 보이고, 그 아래 큰 차트(1일·3개월·1년), 오늘의 요약, 내 종목 카드(현재가·등락·RSI·20/60일선·거래량·52주 범위·기술 흐름)가 나와요. 지수 칸이나 종목 카드를 누르면 큰 차트가 그 종목으로 바뀌어요. 휴대폰에서는 종목 카드가 두 줄로 작게 보이고, 누르면 차트 아래에 지표가 펼쳐져요.

- 시세는 **네이버 증권**의 공개 자료에서 받아요 (키 필요 없음). 장중에는 2분, 장 마감 뒤와 주말에는 30분마다 받아요. 국내 종목·지수의 당일 흐름은 1분 시세로 15분마다 채우고, 미국 지수는 장중에 받은 값을 이어 그려요 (그래서 봇을 켠 뒤 첫 미국 장부터 1일 차트가 생겨요).
- 종목 카드는 `dart.companies` 목록을 그대로 써요 (종목코드 6자리).
- 위쪽 지수 목록은 `market.indices` 에서 바꿔요. `kind` 는 `kr_index`(국내 지수: KOSPI, KOSDAQ, KPI200), `world_index`(해외 지수: .INX, .IXIC, .DJI, .SOX 같은 네이버 코드), `marketindex`(환율·원자재: `category` 와 함께, 예 `exchange`+`FX_JPYKRW`, `energy`+`CLcv1`, `metals`+`GCcv1`)
- 시세 파일(`market.json`)은 저장소의 **market 브랜치**에 올라가요. 자주 바뀌는 파일이라 main과 분리해서 저장소 기록이 쌓이지 않고 Pages 재배포도 일어나지 않아요. 지우지 마세요 (지워도 봇이 다시 만들어요).
- `market.enabled` 를 `false` 로 하면 시세를 끄고 공시·입찰만 써요.
- 기술 흐름 점수(-100~100)는 20일선·60일선·MACD·RSI를 묶은 참고 지표예요. 매수·매도 신호가 아니에요.
- 종목 카드의 신호 칩: ▲ 긍정(빨강) · ▼ 부정(파랑) · ! 주의(주황) · ◎ 관심(초록) · ― 중립. 마우스를 올리거나(휴대폰은 누르면) 실제 숫자로 "왜 그런지" 설명이 떠요. 종목을 누르면 큰 차트 아래에 신호와 이유가 모두 펼쳐져요.
- **1~2일 전망**: 봇이 종목마다 추세(정배열·20일선)·MACD와 그 변화·RSI 과열/침체·오늘 큰 움직임·거래량·최근 이틀 뉴스와 공시·시장 분위기(국내 지수, 미국 증시)를 점수로 합쳐 `상승 우세 / 약한 상승 / 중립 / 약한 하락 / 하락 우세`로 보여줘요. 카드의 전망 칸에 마우스를 올리면(휴대폰은 누르면) 항목별 점수와 이유가 나와요.
  - **적중 기록**: 장이 끝나면 그날 전망을 기록하고, 2거래일 뒤 종가로 맞았는지 채점해요 (중립 제외). 종목별·전체 적중률이 전망 설명 아래에 나와요. 기록이 5건 이상 쌓여야 숫자가 보여요.
- **종목 뉴스**: 국내 주식·ETF·미국 주식 모두 Google 뉴스(한국어)에서 최근 7일 기사를 30분마다 모아 카드와 '공시·입찰 소식'의 **뉴스** 칸에 보여줘요. 제목에 `급락·소송·리콜…`이 있으면 주의, `급등·호실적·목표가 상향…`이면 호재로 표시해요. 국내 주식 카드는 최근 공시가 없을 때 뉴스를 보여줘요.
  - 검색어 바꾸기: 종목에 `"news": "엔비디아 실적"` 처럼 적어요 (기본: 미국 주식은 "이름 주가", 그 밖에는 이름).
  - **디스코드 뉴스 알림 (v2.7)**: 보유·미보유 종목 모두, 아래 조건을 다 맞을 때만 보내요. 끄려면 `market.news_alert` 를 `"none"` 으로.
    - 제목에 종목 이름(또는 `alias` 에 적은 다른 이름·티커)이 들어 있어요. `"news_exclude": ["카카오뱅크"]` 처럼 적은 단어는 빼고 봐요.
    - 강한 표현이 있어요: 급등·급락·폭락·신고가·호실적·목표가 상향/하향·수주·소송·리콜·유상증자 같은 말, 또는 5% 이상 상승·하락 (`news_alert_pct`).
    - 같은 종목·같은 방향(호재/주의)은 3시간에 한 번(`news_alert_cooldown_hours`), 종목당 하루 4건까지(`news_alert_daily_max`). 같은 때 나온 비슷한 기사는 한 알림으로 묶어요.
    - 처음 추가한 종목은 기준만 잡고, 그 뒤 새로 뜨는 기사부터 알려요.

**호출 한도 주의**
- OpenDART는 하루 2만 회까지예요. 지금 설정(보유 10개 · 미보유 1개)은 평일 하루 약 9,900회예요. 미보유 종목은 3분 간격이라 보유 종목의 1/3만 써요. 대략 `보유 수 + 미보유 수 ÷ 3` 이 20을 넘으면 `dart_fast_seconds` 를 120으로 늘리세요. 한도에 가까우면 봇 시작 메시지에서 경고해요.
- 공공데이터포털 개발계정은 보통 하루 1,000회예요. 나라장터는 하루 약 200회를 써요.
- 네이버 시세는 2분마다 7번 안팎(종목은 한 번에 묶어서)만 불러요. 막히면 봇이 5분씩 쉬었다가 다시 시도하고, 30분 넘게 막히면 디스코드로 알려줘요.

## 카카오톡으로도 받기 (선택)

디스코드 알림을 카카오톡 **'나와의 채팅'** 에도 남겨요. 카카오 '나에게 보내기'라서 **카카오톡 알림(진동·소리)은 오지 않아요.** 알림은 디스코드로 받고, 카카오톡은 모아 보는 기록으로 쓰면 좋아요. 무료이고 보내는 횟수 제한이 없어요.

1. https://developers.kakao.com 에 카카오 계정으로 로그인 → **내 애플리케이션 → 애플리케이션 추가** (앱 이름 `투자 레이더`, 회사명은 본인 이름 등 아무거나).
2. **[앱] > [플랫폼 키] > [REST API 키]**
   - REST API 키와 클라이언트 시크릿을 확인해 둬요.
   - **리다이렉트 URI** 에 `https://<GitHub아이디>.github.io/<저장소>/kakao.html` 을 등록해요. (예: `https://kssnit.github.io/invest-radar/kakao.html`)
3. **[카카오 로그인] > [사용 설정]** 에서 상태를 **ON**.
4. **[카카오 로그인] > [동의항목]** 에서 **카카오톡 메시지 전송 (talk_message)** 을 **선택 동의**로 설정.
5. **[앱] > [제품 링크 관리] > [웹 도메인]** 에 아래를 한 줄씩 등록 (알림의 '원문 보기' 버튼이 열리게):
   ```
   https://kssnit.github.io
   https://dart.fss.or.kr
   https://news.google.com
   https://www.g2b.go.kr
   ```
6. S20 Termux에서 `radar update` 후 `radar kakao`
   - REST API 키와 클라이언트 시크릿을 붙여 넣어요 (휴대폰 `.env` 에만 저장돼요).
   - 브라우저가 열리면 카카오 로그인 → **카카오톡 메시지 전송** 동의 → '카카오 연결 코드' 화면에서 **코드 복사** → Termux에 붙여 넣기.
   - '나와의 채팅'에 연결 완료 메시지가 오면 끝. 봇이 자동으로 다시 켜져요.

설정 (`config.json`)
```json
"kakao": {"send": "alerts"}
```
- `"alerts"`(기본): 공시·뉴스·입찰·일정 알림 (봇 상태 메시지는 빼요) · `"important"`: 주의·호재·입찰만 · `"all"`: 디스코드와 똑같이 · `"none"`: 끄기
- 카카오 메시지는 200자까지라 제목·요점만 담고, 버튼으로 원문(공시·기사)이나 대시보드를 열어요.
- 로그인은 쓰는 동안 봇이 알아서 연장해요. 끊기면 디스코드로 알려주니 `radar kakao` 로 다시 연결하면 돼요.

## 문제 해결

**📵 응답 없음 알림이 와요**
1. S20이 켜져 있고 충전기·와이파이에 연결돼 있는지 확인하세요.
2. Termux를 열어 `radar status` → 멈춰 있으면 `radar start`
3. 자주 반복되면 6번 배터리 설정을 다시 확인하세요.
4. 그래도 꺼지고 `radar log` 에 이유 없이 끊기거나 Termux에 `signal 9` 가 보이면, 안드로이드가 백그라운드 프로세스를 강제로 끄는 경우예요. PC에 S20을 USB로 연결하고(USB 디버깅 켜기) 아래 두 줄을 실행하면 대부분 해결돼요.
   ```
   adb shell "/system/bin/device_config set_sync_disabled_for_tests persistent"
   adb shell "/system/bin/device_config put activity_manager max_phantom_processes 2147483647"
   ```

**디스코드 알림이 안 와요**
`radar log` 로 오류를 확인하세요. 웹후크 주소가 바뀌었으면 `radar setup` 으로 다시 넣으세요.

**⚠️ 대시보드 업로드 실패**
GitHub 토큰이 만료됐거나 권한이 빠진 경우예요. 2번처럼 토큰을 새로 만들고 `radar setup` 으로 넣으세요.

**⚠️ 나라장터 실패**
1. 키를 막 발급받았다면 몇 시간 기다려 보세요.
2. **일반 인증키(Decoding)** 를 넣었는지, 활용신청한 서비스가 **낙찰정보서비스**인지 확인하세요.
3. 결과가 이상하면 `config.json` 의 `"inqry_div": "2"` 를 `"1"` 로 바꿔 보세요 (조회 기준을 개찰일시에서 공고일시로 바꾸는 옵션이에요).

**⚠️ 시세 실패 / 대시보드에 시세가 안 보여요**
1. 봇을 v2.3 이상으로 업데이트했는지 확인하세요: `radar update`
2. 첫 실행 뒤 시세가 대시보드에 보이기까지 최대 5분 정도 걸려요 (GitHub 캐시).
3. 계속 실패하면 `radar log` 에서 `시세`·`일봉` 줄을 확인하세요. 특정 지수만 '못 받은 것'에 나오면 그 코드를 네이버가 지원하지 않는 거라 `market.indices` 에서 빼면 돼요. 공시·입찰 알림은 영향이 없어요.

**DART 한도 초과(020)**
봇이 30분 간격으로 자동으로 늦춰요. 다음 날 자정에 한도가 풀려요. 자주 생기면 종목 수나 간격을 조정하세요.

**코드 업데이트**
고친 파일을 받으면 GitHub 저장소에 올리고, S20에서 `radar update`

## 알아 둘 점

- **와이파이 연결을 권해요.** 나라장터 결과 파일이 커서 하루 수십~수백 MB가 쓰일 수 있어요.
- 알림이 오는 시점: DART 공시가 올라온 뒤 대략 1분 안이에요. DART 앱 푸시 알림도 같이 켜 두면 더 확실해요.
- 공개 저장소라서 `config.json`(관심 종목)과 대시보드 내용은 다른 사람도 볼 수 있어요. 키와 토큰은 S20에만 있어요.
- 토큰은 이 저장소 하나에만 권한이 있어서, 유출돼도 다른 저장소에는 영향이 없어요.
- 이 봇은 정보를 빨리 모아 주는 도구예요. 공시 원문을 꼭 확인하고, 투자 판단은 직접 하세요.
